# Playwright Automation Framework 

## Overview
This project is a scalable UI automation framework built using Playwright with Page Object Model (POM) design pattern.

## Features
- Page Object Model (POM)
- Reusable utilities
- Human-like interaction simulation
- Config-driven test execution
- HTML reporting

## Tech Stack
- Playwright
- JavaScript (Node.js)

## Project Structure
- tests/ → test cases
- pages/ → page objects
- utils/ → reusable functions
- config/ → configuration

## Run Tests
npm install  
npx playwright test

## Reports
npx playwright show-report
